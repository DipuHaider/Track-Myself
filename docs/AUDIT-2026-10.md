# TrackMyself audit — October 2026

Scope: the whole repository at commit `4e0d845` (11 October 2026): project setup, auth, backend,
frontend, profile, admin dashboard, application flow, AI, feature inventory, SaaS readiness,
design, notifications, database, caching and deployment, measured against `README.md`,
`CLAUDE.md`, `docs/GOALS.md` and `docs/TrackMyself_AI_Work_Plan.md`.

Method: three read-only code audits (backend/auth/DB, frontend/UX/dashboard, AI/features/docs
drift), every critical and high finding re-verified by hand against source, then a single
remediation pass. "Status" below says what happened to each finding in that pass.

Severity: **C** critical, **H** high, **M** medium, **L** low.

## Critical and high

| # | Area | Finding | Status |
|---|---|---|---|
| C1 | Auth | Registration never proved inbox ownership, and Google sign-in merged into any existing row with the same email. Superadmin addresses are hard-coded, so registering one first could capture the platform. | **Fixed.** Email verification (24 h token, Resend), credentials login refuses unverified accounts, Google replaces an unverified password row and voids its tokens, `effectiveRole()` grants superadmin only when verified. Legacy accounts are grandfathered (absent field = verified). |
| H1 | Security | A user's own OpenAI-compatible key accepted any base URL; the server POSTed to it and echoed the response (SSRF to metadata/internal hosts). | **Fixed.** `assertSafeBaseUrl()`: https only, no credentials, public host name, DNS checked against private/link-local/metadata ranges, optional allowlist, re-checked at call time, no body echo for user keys, redirects not followed, 5 probes / 10 min. |
| H2 | DB | `Application` had only a `deletedAt` index; `Interview` none. | **Fixed.** Compound indexes on `userId`; `Interview.userId` + `{applicationId, scheduledDate}`; `Document.applicationId`; `ensure-indexes` migration. |
| H3 | Auth | Emails not normalised: login looked up as typed, reset/extension lowercased. | **Fixed.** Schemas lowercase+trim, `User.email` lowercase, all lookups normalised, `normalise-emails` migration reports conflicts. |
| H4 | AI | A user's own key still consumed the free 10-attempt shared allowance. | **Fixed.** BYOK calls skip the attempt counter (still rate-limited and logged as `funding: user`). |
| H5 | AI | BYOK did not unlock premium AI tasks although README/FAQ said it did; entitlement was per route. | **Fixed.** `aiEntitlement()` in the gateway: own key → every task on any plan; premium → shared; free → 10 shared uses/month then the feature's non-AI mode. |
| H6 | Data | Account deletion left `AiCallLog`, `AiUsageCounter`, `RateBucket` rows and orphaned attachments; not transactional. | **Fixed.** Ordered, per-step isolated purge covering every userId-scoped collection; `User` row deleted last; partial failures retried by the maintenance job. Forever-delete cascades attachments. |
| H7 | API | Unbounded reads: applications list, admin applications/CV/users, notifications derive. | **Fixed.** Pagination envelopes, projections, light stats endpoint, exact derive projection, hourly purge throttle. |
| H8 | Frontend | No `error.tsx` / `global-error.tsx`. | **Fixed.** Root + per-zone boundaries with Sentry capture. |
| H9 | Frontend | Client loaded every application; `/me` fetched the list again for stats. | **Fixed.** Server pagination, URL-driven filters, `/api/applications/stats`. |
| H10 | Frontend | Upgrade CTAs led nowhere. | **Fixed.** `/pricing` page, provider-agnostic billing layer, request-upgrade flow. |
| H11 | A11y | Form labels unlinked; 7 drop zones unusable by keyboard. | **Fixed.** `useId` labels, shared `DropZone`. |
| H12 | Admin | No audit log. | **Fixed.** `AdminAction` model, every admin mutation logged, `/dashboard/audit`. |
| H13 | Paused accounts | 15+ write/AI routes ignored the paused state. | **Fixed.** AI spend and application/admin writes are Active-gated; the CV builder, tools, to-dos and profile stay usable, as the product rule says. |

## Medium (fixed in this pass)

- Login throttle per email only → per-IP bucket added, constant-time dummy compare.
- RBAC escalation via `edit:users` → self-edit blocked, rank ceiling (`canManageRole`, `canAssignRole`).
- Open redirect through `/\evil.com` → `safeReturnTo()` with origin check.
- Extension: any extension id accepted when `EXTENSION_IDS` unset → fails closed in production; `aud` checked on Bearer tokens; CORS per request keyed on extension ids.
- Upload: malformed filename regex, no magic-byte check, 8 MB cap above Vercel's 4.5 MB body limit → fixed, sniffed, 4 MB, per-user caps, rate-limited.
- `admin/users` and `user/profile` leaked encrypted key material, `googleId`, `notifSeen` → allow-list serialisers.
- Admins could set the AI money ceiling to $1000 → hard cap USD 10, superadmin only.
- Gemini superadmin fallback unreachable → restored inside the gateway as a superadmin-only retry.
- Preview drafts stored as byte-less `CVFile` rows, shown in My Documents, never expiring → `AiDraft` model with TTL; `purge-preview-cvfiles` migration.
- Interview questions billed on preview and on download → cached per job.
- Triage reused the gap-analysis task id → `applications.triage`.
- No schema validation of model output; job text injected without delimiters; no provider timeout → zod schemas with one repair retry, fenced `<data>` blocks under a system prompt, 60 s timeouts, no redirects.
- Per-process rate limits (3) and unlimited routes (9) → all DB-backed.
- `clientIp()` trusted `X-Forwarded-For` → platform headers first.
- `notifSeen` unbounded; dismissals did not stick; no per-type mute → bounded `$slice`, `notifDismissed`, `notifPrefs`.
- Theme toggle reverted after reload; a11y prefs only fetched when the modal opened → single source of truth, `A11ySync` at sign-in.
- No status tokens; light-only hex panels; dark `.btn-primary` below AA; `dark:` variants; ~200 raw palette classes → tokens, `.alert-*`, dedicated dark button gradient, ESLint guard.
- Modals without focus trap / scroll lock / veto; nested Escape closed both layers → hardened `Modal`, modal stack, `useUnsavedChanges`.
- Table showed "No applications" while loading; no mobile layout; silent quick-update failures → skeleton, cards, optimistic updates with rollback.
- Paused user's `/me` crashed → profile readable while paused.
- Auth pages did not redirect signed-in users → `(auth)/layout.tsx`.
- `/dashboard` called the DB without `force-dynamic` → added.
- `.claude/settings.local.json` and a stray upload screenshot were tracked → untracked, ignored.
- CSP `'unsafe-eval'` everywhere → eval only in development; `'wasm-unsafe-eval'` only under `/tools`.
- `NODE_TLS_REJECT_UNAUTHORIZED=0` on any non-production `NODE_ENV` → also requires `DEV_INSECURE_TLS=1`.
- `engines` lacked Node; `@types/node` 20 on Node 22; `eslint-config-next` behind `next` → aligned.

## Residual risk and deferred items

- No 2FA. No email change flow (the address is the identity; change by support).
- `CVProfile.userId` and `CVFile.userId` remain `String` while other models use `ObjectId`
  (documented quirk; Mongoose casts through the models).
- No billing provider: the layer is wired and the checkout returns 501 until an adapter exists.
  See `docs/ROADMAP.md` for the selection criteria.
- Component-level UI tests need `@testing-library/react` + `jsdom` (not added); DB-backed tests
  run only with `MONGODB_TEST_URI`.
- GitHub Actions are pinned by tag, not SHA (no authenticated `gh` in the workstation to resolve
  them); Dependabot keeps them current.
- Branch protection must be enabled in GitHub settings for CI to gate deploys (see README).

## How to re-run this audit

```bash
npm run verify          # typecheck + lint + env check + unit tests
npm run typecheck:ext   # browser extension
npm audit               # dependency advisories
npx eslint src          # the palette/dark: guard reports any regression
```

Then re-read `README.md` against `src/` (every path it names must exist), and run the
migrations list in `src/lib/migrations/index.ts` on a copy of production data.
